# Matheus Alexandre - Portfólio

## Sobre o Projeto

Portfólio pessoal de Matheus Alexandre, desenvolvedor Full Stack.

## Tecnologias Utilizadas

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion

## Como Rodar Localmente

```sh
# Clone o repositório
git clone <URL_DO_SEU_REPOSITORIO>

# Acesse o diretório do projeto
cd matheus-portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## Build para Produção

```sh
npm run build
```
